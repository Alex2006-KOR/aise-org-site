# AISE란 무엇인가

AI는 빠르게 발전하고 있고 앞으로도 새로운 모델과 도구가 계속 등장할 것입니다. 하지만 인간
조직은 같은 문제를 반복합니다 — 개인은 망각하고, 조직은 경험을 충분히 쌓지 못하며, 같은
문제를 처음부터 다시 풉니다. AI가 아무리 뛰어나도 세션이 끝나면 그 능력은 조직에 남지
않습니다.

**AISE(ai-sw-engineering)**는 이 문제를 풀기 위해 만들어졌습니다. AISE의 목적은 특정 AI
모델을 더 잘 쓰는 것이 아니라, AI를 활용해 **지속적으로 성장하는 조직**을 만드는 것입니다. AI는
이 조직의 구성원이며, 조직의 역량은 시간이 지날수록 쌓여야 합니다.
