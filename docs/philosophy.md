# Philosophy

AISE는 다섯 가지 철학 위에 서 있습니다.

1. **조직이 중심이다** — AI는 목적이 아니라 조직의 목표를 수행하는 구성원입니다. AI 도구는
   언제든 교체될 수 있지만, 조직의 철학과 운영 방식은 유지됩니다.
2. **조직은 기억해야 한다** — 인간은 잊지만 조직은 잊어서는 안 됩니다. 반복적으로 쓰이는
   지식과 경험은 반드시 지식자산으로 축적됩니다.
3. **조직은 지속적으로 성장해야 한다** — 새로운 문제는 새로운 역량을 만들 기회입니다. 한 번
   해결한 문제는 다음엔 더 빠르고 정확하게 풀립니다.
4. **책임은 명확해야 한다** — 모든 업무에는 반드시 책임자가 있습니다. 협업은 자유롭지만
   책임은 흐려지지 않습니다. (다만 AI Agent는 법적·최종적 책임의 주체가 될 수 없습니다 — 여기서
   "책임자"는 감사 추적상의 오너, 즉 "문제가 생기면 어떤 역할이 검토했어야 했는가"를 추적하는
   라벨이며, 최종 책임은 조직을 운영하는 사람에게 있습니다.)
5. **AI의 장점을 최대한 활용한다** — AISE는 인간 조직을 그대로 복제하지 않습니다. 인간 조직의
   장점은 유지하고, AI가 가진 능력은 최대한 살리도록 다시 설계합니다.
