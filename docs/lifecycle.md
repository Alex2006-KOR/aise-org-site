# Lifecycle

AISE의 조직은 다음 여섯 단계를 거쳐 지속적으로 성장합니다.

1. **채용(Recruitment)** — 필요한 역량이 없으면 새 Agent를 만듭니다. 다만 마찰 없이
   반복 가능하다는 이유로 무분별하게 늘리지 않습니다 — 기존 역할로 흡수할 수 있는지 먼저
   확인하고, 조직이 취할 수 있는 형태(뎁스-2 피라미드)를 벗어나지 않는지, 사유가 구체적인지
   확인합니다.
2. **책임 부여(Assignment)** — 새 Agent에게 역할과 책임을 명확히 부여합니다.
3. **협업(Collaboration)** — 업무 수행을 위해 실행 그래프를 구성합니다. 필요한 Agent는 자유롭게
   협업합니다.
4. **보고(Reporting)** — 모든 업무 결과는 책임자에게 보고됩니다. 보고 체계는 조직도를 따릅니다.
5. **피드백(Feedback)** — 리뷰와 피드백은 조직의 학습 과정이며, Workflow와 지식자산에
   반영됩니다.
6. **지식자산화(Knowledge Accumulation)** — 새로 얻은 경험은 Workflow / Capability /
   Framework / Portfolio 같은 지식자산으로 쌓입니다. 조직은 같은 문제를 두 번 처음부터 풀지
   않습니다.

실제 운영에서 하나의 부서(project)는 `draft → active → ended → closed`라는 생명주기를 거칩니다
— 요청이 아직 불분명하면 `draft`에서 가볍게 대화하며 다듬고, 사용자가 명확히 승인하면
`active`로 실제 위임이 시작되며, 사용자가 완료를 지시하면 `ended`, 지식누적 리뷰(회고 작성,
재사용 가능성 검토)를 마치면 `closed`가 됩니다.
