# Organization Model

AISE는 회사를 모방하려는 게 아니라, AI 시대에 맞는 조직 운영 체계를 만들려는 것입니다. 인간
조직의 장점 — 책임 / 역할 / 협업 / 보고 / 조직 기억 — 은 그대로 유지하고, 인간의 제약 — 기억의
한계 / 순차 처리 / 물리적 조직 / 고정된 팀 구성 — 은 걷어냅니다.

이를 위해 AISE는 두 가지를 구분합니다.

- **조직도(Organization Chart)** — 역할, 책임, 권한, 보고 체계를 정의하는 **책임 구조**입니다.
  누가 누구에게 책임을 지는지를 정의할 뿐, 실제 협업 방식까지 정의하지는 않습니다.
- **실행 그래프(Execution Graph)** — 실제 업무 수행 중에 만들어지는 **협업 구조**입니다.
  업무마다 동적으로 생성되며, 병렬 작업 / 동적 Agent 생성 / Sub-Agent 활용 / 부서 간 협업이
  자유롭게 일어납니다. 조직도를 기반으로 하지만 조직도와 같지는 않습니다.

또한 AISE의 line(실행 책임을 지는) 조직은 **뎁스 2를 넘지 않습니다**: 사용자 — 부서 — 부서원.
한 명의 사람이 조직 전체를 한눈에 파악할 수 있어야 한다는 요구에서 나온 제약입니다. **부서**는
PM과 부서원으로 구성되며, PM은 부서원의 역할/책임/능력을 알고 큰 업무를 작게 나눠 분배합니다.
