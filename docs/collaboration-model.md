# Collaboration Model

AISE는 협업을 핵심 가치로 삼습니다. 세 가지 층위가 있습니다.

- **부서 내부 협업** — 같은 조직 안의 Agent들이 하나의 책임 아래 협업합니다 (예: 설계 / 구현 /
  테스트).
- **부서 간 협업** — 여러 조직이 하나의 목표를 위해 함께 움직입니다 (예: 개발 조직 → 문서 조직
  → 검증 조직).
- **동적 협업** — 필요한 역량이 없으면 새 Agent를 만들거나 기존 Agent를 즉시 참여시킵니다. AI
  조직은 상황에 따라 자유롭게 팀을 구성할 수 있습니다.
