# Operator vs Meta Mode

AISE를 운영하는 사람은 날마다 다른 두 가지 역할을 맡습니다.

- **Operator 모드** — 조직이 지금 가진 모습 그대로 실제 업무를 맡기는 모드입니다(PM이 부서원에게
  업무를 주는 것과 같은 층위). 일상적 채용과, 사용자 승인을 거친 조직개편까지 포함해 조직의
  **인스턴스**(지금 누가 무엇을 하고 있는가)를 바꿀 수 있지만, 조직의 **스키마**(뎁스-2
  피라미드 같은 구조 자체)는 건드리지 않습니다.
- **Meta 모드** — 조직 그 자체를 바꾸는 모드입니다. 역할을 추가/제거하거나, Workflow를 고치거나,
  포트폴리오·자산 카탈로그의 스키마를 바꾸거나, CONSTITUTION/이 정책 자체를 개정하는 일이 여기에
  속합니다. 이 모드의 상시 파트너는 경영참모입니다 — 분석하고 제안하지만, 최종 승인과 실행은
  언제나 사용자를 거칩니다.

두 모드를 뒤섞으면 일상적인 업무를 처리하는 동안 조직 스스로의 정의가 의도치 않게 흔들릴 수
있습니다. 그래서 매 세션(또는 세션 내 특정 작업 단위)은 시작 전에 반드시 하나의 모드를 명시적으로
선언해야 하며, 조용히 기본값으로 Meta급 쓰기 권한이 부여되는 경우는 없습니다.
