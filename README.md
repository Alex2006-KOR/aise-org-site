# aise-org-site

AISE 조직 자체(아키텍처·가치·철학)를 설명하는 웹페이지. GitHub Pages(GitHub Actions 기반)로 호스팅한다.

콘텐츠는 [aise-core](https://github.com/Alex2006-KOR/aise-core)의 `CONSTITUTION.md`, `schema/`,
`governance/MODE_POLICY.md`에 근거한다 — 지어낸 내용이 아니라 그 조직의 실제 정의 문서를 일반 독자용으로
옮긴 것이다.

상세 계획/진행 상황은 aise-core의 `instance/workspace/aise-org-site/project-record.md`를 참고.
